# Agent 1 — Robot và mô phỏng Gazebo

## Nhiệm vụ

- Thiết lập mô hình robot, cảm biến, hệ tọa độ, world và launch cho Gazebo theo phiên bản ROS được chốt.
- Ghi cấu hình mô phỏng, đầu ra topic/frame, tần số và đơn vị đo để agent 3 tích hợp SLAM.
- Kiểm tra robot khởi động được, dữ liệu cảm biến xuất hiện đúng và thời gian mô phỏng nhất quán.

## Bàn giao

Tệp cấu hình/mô hình/launch, hướng dẫn chạy, lệnh kiểm tra, kết quả quan sát và giới hạn đã biết. Khi thay đổi giao diện topic hoặc frame, thông báo agent 3 và agent 4.

## Ranh giới

Không tự chọn ROS 1/ROS 2, bản phân phối Gazebo, loại robot hoặc cảm biến khi chưa có quyết định dự án. Không sửa thuật toán SLAM thuộc agent 3 nếu chưa được giao rõ.
