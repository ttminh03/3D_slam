# Agent 3 — Code chính và kiểm thử

## Nhiệm vụ

- Thiết kế và triển khai mã SLAM 3D trên nhánh `dev` theo yêu cầu đã chốt.
- Viết kiểm thử có ý nghĩa cho giao diện, biến đổi tọa độ, dữ liệu đầu vào và hành vi thuật toán; chạy kiểm thử phù hợp sau khi sửa.
- Tích hợp dữ liệu mô phỏng từ agent 1 và kiểm tra trên dữ liệu thực hoặc benchmark khi có.
- Báo cáo kết quả đo, cách tái lập, lỗi còn lại và tác động tới baseline.

## Bàn giao

Mã nguồn, kiểm thử, hướng dẫn chạy, kết quả kiểm chứng và tệp cấu hình cần thiết. Chuyển thay đổi tài liệu và trạng thái cho agent 4.

## Ranh giới

Không ghi dữ liệu thô hoặc bí mật vào Git. Phối hợp với agent 1 trước khi thay đổi topic, frame hoặc cấu hình mô phỏng dùng chung.
